# 🚀 AI Automated Global News & Magazine Platform

An enterprise-grade automated news and blogging web application powered by **Google Serper API** (for real-time Google News & HD Photos) and **Google Gemini AI** (for 800-1,100 word high-CTR professional news reporting).

## 🌟 Key Features
- **🤖 24/7 Autopilot Engine:** Scans worldwide breaking news and auto-publishes high-demand news stories.
- **📰 Zero Template Policy:** Every article is 100% uniquely crafted by Gemini AI based on live facts.
- **📸 Hotlink Shield & HD Photos:** Integrated Serper Images search with fallback image pools.
- **🛡️ Admin Security:** Protected by token authentication, masked API key managers, and dynamic settings persistence.
- **📊 Real-Time Audience Analytics:** Live country-wise page views and top trending article stats.
- **🚀 Cloud Ready:** Built for 1-click deployment on Railway.app, Render, or VPS.
